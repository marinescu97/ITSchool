**ITSchool** is a structured Java project created to practice and demonstrate programming skills.  
It contains multiple **sessions**, each with exercises and assignments that cover different levels of Java knowledge.

---

## 🚀 About the Project

This repository is a collection of **Java exercises** organized by learning sessions.  
It demonstrates my ability to:

- Write clean and efficient **Java code**
- Apply **Object-Oriented Programming (OOP)** concepts
- Solve problems using **algorithms and data structures**
- Organize and structure projects professionally

---

## 🛠️ Skills & Technologies

- **Core Java (SE 21)**
- **OOP Principles** (classes, objects, inheritance, polymorphism)
- **Data Structures** (arrays, ArrayList, HashMap)
- **Control Flow** (loops, conditions, operators)
- **File Handling** (reading & writing files)
- **Lambdas & Streams API**
- **Exceptions & Error Handling**
- **Concurrency & Multithreading**
- **Design Patterns** (Singleton, Factory, Builder, etc.)
- **Clean Code Practices** (readability, modularity, maintainability)
- **IDE**: IntelliJ IDEA / Eclipse

## 📂 Project Structure

- [Session1](src/main/java/session_1_java_basics) — Basics (variables, printing)
    - Example: `MyFirstProject.java`, `Homework.java`
- [Session4](src/main/java/session_4_operators_and_statements) — Operators & Statements
    - Example: `ForStatements.java`, `JavaStatements.java`
- [Session10](src/main/java/session_10_OOP) — Object-Oriented Programming
    - `Homework/` — Homework projects (e.g. `College Management System`, `Simple Banking Application`)
- [Session15](src/main/java/session_15_javaCollections) — Java Collections
    - Example: `ListPractice.java`, `MapPractice.java`
- [Session18](src/main/java/session_18_Streams) — Java Streams
    - Example: `Exercises`, `ExpenseTracker`

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/marinescu97/ITSchool.git
   cd ITSchool

2. Compile & run any exercise:
    ```bash
    javac src/main/java/session_1_java_basics/MyFirstProject.java
    java -cp src/main/java session_1_java_basics.MyFirstProject

Or open the project in IntelliJ IDEA or Eclipse and run directly.
